# AegisVault Mobile 1.4

versionName **1.4** / versionCode **6**. Debug-signed test release / debug 签名测试版，沿用既有签名身份。

- Safe, shared settings decoding for reads and atomic edits; valid values are preserved, unknown enums and wrong types have explicit defaults.
- Actual DataStore corruption handler restores protective settings. Read I/O retains last known preferences and retries with bounded backoff; write I/O is reported and later edits remain possible. Cancellation and programming errors propagate.
- Bilingual persistent-in-session recovery notices require acknowledgement and survive text actions and sensitive clearing. Screen capture protection is enabled while settings initially load.
- No input, password, plaintext or result persistence. Only the five existing non-sensitive preference keys are written.
- Retains 1.1–1.3 task cancellation, strict JSON/raw-header AGV1 authentication, isolated migration, Base64 modes, exact input semantics and Android resource budgets.

Validation: **62 Android test methods**, **6 offline migration tests**, **783 actual frozen desktop comparisons**, lint **0 errors / 40 existing warnings**, APK build/version/signature checks passed. Includes real Preferences DataStore disk reads, unknown/type-anomalous values, corrupted protobuf and file read/write I/O with successful recovery and later edits. Physical-device acceptance is **NOT RUN**: no device connected. Local JVM/filesystem evidence does not replace Android device evidence.
