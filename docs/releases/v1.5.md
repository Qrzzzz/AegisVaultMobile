# AegisVault Mobile 1.5

versionName **1.5** / versionCode **7**. Debug-signed test release / debug 签名测试版，沿用既有签名身份。

- Settings provides manual stable GitHub release checking, download progress/cancel, release notes and an Android installer entry.
- Standardized `update-manifest.json` schema v1 generated from verified APK metadata; numeric major.minor/versionCode ordering, exact package identity, minSdk, size, SHA-256 and signing certificate are validated.
- HTTPS-only fixed repository, bounded bodies/timeouts/redirects and downloads. No token, personal text or password is transmitted; no startup/background polling or silent installation.
- Streamed APK verification, private cache, narrowly scoped FileProvider, installed signer matching and explicit Android installation permission/system confirmation.
- From 1.5, release assets include APK, SHA256SUMS.txt and update-manifest.json. Legacy two-asset release verification is retained.

Local validation: **79 Android/JVM test methods** including an explicitly enabled actual GitHub HTTPS smoke; **7 update contract/verifier tests**, **6 migration tests** and **783 actual desktop comparisons** passed. Lint: **0 errors / 40 existing warnings**; APK/package/version/minSdk/signer and generated manifest checks passed. Ordinary CI skips the opt-in network test and runs the deterministic suite. The previous two-asset v1.4 Release was also verified with the updated verifier.

Physical-device download/install/permission/upgrade and UI acceptance remain **NOT RUN**: no connected device. Host metadata checks, mocked TLS connections and identity-policy tests do not establish Android installer or FileProvider acceptance. Earlier non-file cryptography, migration, Base64, lifecycle and settings recovery are retained; #5's physical-device gate remains open.

中文：设置内手动检查 GitHub 最新正式版，下载 APK 并校验大小、SHA-256、包名、版本、最低系统版本及签名一致性后，由用户打开 Android 系统安装界面。无自动安装或启动轮询；文本、口令和结果不进入更新请求。更新元数据采用版本化标准合约，从 1.5 起发布 APK、SHA256SUMS.txt 和 update-manifest.json 三份附件；旧版本验证保持兼容。
