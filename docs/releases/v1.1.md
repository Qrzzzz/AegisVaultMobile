# AegisVault Mobile 1.1

本次更新修复非文件后端的任务生命周期与资源安全，versionName **1.1**，versionCode **3**。

- 防止清空、自动清空离开、销毁或编辑后的旧任务恢复敏感输入/口令，或覆盖新模式与设置；取消与乱序完成仅允许有效任务提交。
- scrypt 派生前严格检查 JSON 字段类型、32-byte key、实际盐长度及总内存/工作量。Android 暂行内存上限64 MiB，默认参数保持不变。
- 分离正文、编码token、元数据和解码结果预算，修复30 KiB普通文本加密失败；补充中英资源错误提示。
- 产品版本与APK命名采用主.次版本；冻结桌面合约及历史Android迁移样本。

This update fixes stale worker completion, KDF validation and text/Base64 resource budgets. It retains the existing Android writer and legacy readers. Product version is now major.minor; dependency versions and historical releases remain unchanged.

## 验证与限制 / Validation and limitations

34 local Android unit tests, lintDebug and assembleDebug passed. The release workflow repeats tests/lint/build before publishing and verifies the APK version, existing test signer and SHA-256 manifest. Lint has warnings; device acceptance has not been performed because no device was available.

**仍无法与桌面互解 / Desktop interoperability remains unavailable.** Mobile 1.1 still uses JSON AGV1 with no header AAD, and keeps old AES/AK# readers. The shared AGV1 prefix does not mean the protocols are compatible. Plaintext/password budget is 1 MiB, encoded token 2 MiB, metadata 16 KiB; this does not cover every desktop maximum boundary. Protocol alignment and explicit legacy migration are planned for 1.2, full Base64/input/settings alignment for 1.3, non-file device acceptance for 1.4.

**APK is debug-signed for testing**, using the same test certificate as the previous 1.0.1 artifact. It is not a production-signed security release. Assets: `AegisVaultMobile-v1.1-debug.apk` and `SHA256SUMS.txt`. Verify the checksum before installation. File encryption/Base64, batch/path/recent-file work and UI redesign are excluded.
